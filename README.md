# 淡水・職責安排

瀏覽器內執行的繁體中文職責安排工具。名單不會傳送到伺服器，也不會保存在瀏覽器儲存空間。

## 功能

- 匯入 UTF-8（含 BOM）或 Big5 CSV，自動列出資料中的月份。
- 分為「週中聚會」與「週末聚會」的整月安排表（週中非星期四的日期整欄以橘色標出）；音控、麥克風、招待以藍黃綠分區。
- 選擇姓名製作個人通知，淡水山海與橋梁圖案為程式繪製。
- A4 PDF / 高解析 JPEG。多頁 JPEG 自動打包 ZIP；個人超過七項服務會自動分頁。
- 依 PDF 或 JPEG 格式，全員通知一次 ZIP 下載。
- 每人服務次數、服務天數、明細及可調提醒門檻；同日兼任分別計次。
- 姓名支援「名 姓」轉「姓名」或保留原樣。重複的日期＋原姓名＋職責資料只計一次。

## 使用

開啟網站，選擇 CSV → 月份 → 整月／個人 → PDF／JPEG → 下載。示範資料均為虛構姓名。

必要欄位 `Date,Person,TypeName`；可附帶 `Type` 等欄位。日期接受 `YYYY/MM/DD` 或 `YYYY-MM-DD`。

```csv
Date,Person,Type,TypeName
2026/11/05,示範弟兄甲,Duty4P1,音頻控制員
2026/11/07,示範弟兄乙,Duty6P1,講台
```

額外職責（如機動人員）會保留。整月表同格多人會並列，每個類別最多五個日期欄位，超出會拆表；每頁兩個表。沒有安排的日期不會憑空加入。門檻僅是提醒，不代表每項服務負擔相同。

## 開發及部署

不需要 npm 依賴或建置，Node.js 18+ 可執行測試：

```sh
npm test
npm start
```

開啟 http://localhost:4173 。將 網站根目錄 部署到任意靜態網站主機即可。PDF 使用 canvas 產生 JPEG 再嵌入 A4 頁面，中文字不依賴 PDF 字型，但 PDF 文字無法選取搜尋；實際字型依裝置的中文字型而異。ZIP 使用 UTF-8 檔名和 CRC32 校驗。

正式名單與原始附件未加入原始碼。瀏覽器重新整理會清除上傳資料。請下載後再以適當管道分享。
